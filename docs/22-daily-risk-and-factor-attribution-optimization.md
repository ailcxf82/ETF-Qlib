# 本轮优化：每日风控与因子增量诊断

日期：2026-09-28。实施范围为研究回测、诊断报告及测试，不启动新付费 campaign，不访问券商，不改变历史试验结论。

## 1. 本轮证据与目标

`rdagent-mechanism-20260928` 五次候选均完成并拒绝。趋势效率、资金流、隔夜跳空分别有 3/5、4/5、4/5 折通过方向化 IC/ICIR，但没有一个通过完整配对验收。

抽查旧基线 E 折风险记录：126 个交易日中 114 天标记 `not_scheduled_rebalance`，仅 12 天检查风险。旧决策同时使用当日开盘价判定风险并尝试同开盘成交，不能证明可实现的时间顺序。优化目标是修复这种执行机制缺口、定位信号到收益的损耗，而不是通过改阈值让旧因子合格。

## 2. 实施计划与范围

- [x] 将风险减仓与普通模型调仓分开记录，保留真实交易约束与逐笔结果。

- [x] 增加逐折/种子/成本倍数的门槛值、实际值和超限幅度，不放松验收。
- [x] 增加真实 Qlib 合成场景和报告边界测试。

## 3. 风控时序与行为

1. t 日收盘：Qlib 完成每日记账，策略记录含成本/收入的权益、收盘高水位和收益历史。
2. t+1 日决策：使用 t 日已完成收盘证据检查风险；即使不是调仓日、没有模型预测，也不能跳过。
3. 触发回撤风险：按实际持有份额生成清仓卖单，不用 t+1 开盘价格反过来决定是否触发。
4. 波动率模式：至少具备 20 个已完成交易日收益才可判断；超限时仅缩减已有份额，不新增买入。
5. 交易所适配器按 t+1 开盘报价、限价、成交量参与率、佣金和最小交易单位处理；无法成交和部分成交均有回执。下一日仍触发风险时继续尝试剩余持仓。
6. 未触发风险：仍只在原调仓日执行模型调仓。缺预测可跳过调仓，但当天风控记录仍存在。

保留重要边界：

- 触发阈值仍为已冻结参数，不承诺跳空、无法成交时实际最大回撤不超线。
- 使用收盘高水位，不再把当日开盘权益更新到风险决策高水位。
- 未新增自动重置高水位、冷静期或重新入场规则。清仓后如果权益仍低于原高水位门槛，会继续保持风险状态；不得靠重置峰值制造风险通过。
- 普通模型调仓仍用当日开盘价换算目标份额，明确记录 `current_session_open_target_weight_sizing_unverified`；本次只消除风险触发与同开盘成交的前视关系，不声称整个交易模型已达到实盘执行验收。
- 风险决策记录 `decision_kind=risk_reduction`，不伪造模型目标权重；实际仓位以每日持仓及独立账本为准。
- 开始日没有前一交易日时如实记录 `no_prior_session`，不补造风险历史。

## 4. 报告和验收

`risk_checks.json`：每日检查、是否计划调仓、决策估值基础、订单数量基础、风险卖出意图。

`development_diagnostics.json / signal_to_execution`：

- `model_feature_entry`：校验模型 manifest 哈希后比较新增/移除的模型输入列，不加载 pickle；声明进入模型不等同于模型实际使用或特征重要性。
- `prediction_change`：仅比较实际回测交易日上的预测行，记录变化行数、平均/最大绝对差；不混入训练日期，不冒充经标签成熟度/资格过滤的 IC 样本；索引不完整为 partial，非有限值拒绝。
- 原有排名、选股、目标权重及成交约束诊断继续保留；风险专用决策不混入模型排名统计。
- `risk_only_decisions` 单独统计；`execution_cost_delta` 统计整个共同回测区间成本，另留匹配调仓日的成本差，避免漏掉非调仓日风险交易。
- 所有观察仍为非因果归因；旧模型声明缺失保持 unknown，旧风险时序保持原记录，不升级历史证据。
- 新增预测变化计数和风险减仓次数经白名单压缩接入 RDAgent 反馈；模型仅收到紧凑摘要，不收到完整逐日矩阵、本地路径或原始预测。

`evaluation.json / gate_details`：逐折/种子记录风险、回撤恶化、换手恶化、权重限制，逐成本倍数记录压力风险及收益；另记录种子收益中位数门槛。原有 `reasons` 和最终 verdict 仍为验收结果。

方向在训练期确定，五折至少三折同时 IC>0 且 ICIR>0；压力收益最低 -0.03；回撤及换手恶化容忍度不变；种子、消融、组消融、数据与留出边界均不放松。
