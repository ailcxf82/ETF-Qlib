## 3. 已填写的六项默认值

这些是预先设定的**工程默认验收线**，不是已测行业平均数或收益承诺。查到的原始资料没有给出一套可直接移植到本项目的“中国ETF因子统一合格值”。具体依据分开列明，不对不同市场、资产、频率和杠杆的数值求平均。

| 配置字段 | 默认值 | 口径、适用场景和理由 |
| --- | ---: | --- |
| `minimum_net_return` | 0.03 | 基础场景整个确认窗口扣模型内执行成本后的**累计净收益≥3%**。代理选择的最低经济收益线，不是年化平均或无风险收益率；不含未建模的账户税费/LLM费用 |
| `minimum_excess_return` | 0.01 | 同期累计净收益减CSI300累计收益，至少**1个百分点**；并非复合相对收益或相对配对模型的增量。代理选择的最低增益线；CSI300未必与混合ETF风险匹配，沿用原基准以防择优换基准 |
| `maximum_drawdown` | 0.12 | **≤12%**，基础与全部压力场景均适用，沿用用户原风险边界；这是验收限制，不保证跳空/停牌时实际亏损能锁在12% |
| `maximum_annualized_volatility` | 0.15 | 日收益按现有252日年化口径，基础与压力均**≤15%**。以公开风险预算案例作量级参考后选择的上限，不是行业均值，也不是波动目标控制器 |
| `maximum_execution_cost_over_initial_equity` | 0.02 | 确认窗口内累计执行成本／初始权益**≤2%**，基础与压力分别检查；不是每笔手续费率，不是基金管理费，也不是LLM账单 |
| `minimum_effective_dates` | 252 | 基础与压力均至少**252个有效收益日期**；代理选择的约一年最低观察门槛，不是252个独立同分布样本，也不证明统计显著 |

所有比较沿用原判定器：等于阈值允许，超界才拒绝（回撤、波动、成本沿用现有数值容差）；缺失/NaN和账本不平归为数据质量错误，不能用上表填补。

既有条件另外保留：2倍佣金/滑点等执行成本下累计超额收益≥-3%，配对、消融、折/seed稳定性、换手及风险门槛不变；研究预算unlimited、有限campaign5次、每trial5次dispatch/2次repair及8小时控制不变。压力场景不另外套基础3%/1%收益门槛，这是既有判定口径。

成本2%的工程含义举例：当前单边佣金0.03%加滑点0.03%，粗略每成交1倍初始权益耗费0.06%；2倍压力为0.12%。忽略权益变化等因素时，2%压力成本预算约支持16.7倍累计成交金额／初始权益。每月两次调仓不等于每次全部换仓；实际按成交账本计算，不能把这个粗算当成供应商实际费率或最终测量。

### 外部依据与不能外推的边界

1. [CFA Institute：Backtesting & Simulation](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/backtesting-and-simulation) 支持滚动回测、压力/敏感性分析及前视和幸存者偏差检查；不规定本项目3%、1%、12%或2%的数值。
2. [AQR Style Premia Alternative Fund公开招募说明书（SEC）](https://www.sec.gov/Archives/edgar/data/1444822/000119312526198088/d42635d497k.htm) 给出10%的年化波动目标和通常8%—15%的预期目标范围，并明确实际波动可能不同。这是全球多资产多空基金的单个案例，不是中国ETF长仓策略的平均值。本项目15%是参考量级后的自主上限。
3. [GIPS Standards Handbook，2.A.12、4.C.36](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/) 不允许把不足一年的收益直接年化展示；相关三年事后波动披露使用36个月收益。这不要求本项目必须等待三年，也不证明一年足够；252日是项目默认，收益仍按累计值判定。本文不宣称符合GIPS认证。

来源核查日期为2026-09-26；没有采购数据或读取留出表现来校准这些阈值。

## 4. IC / ICIR与合格结论的关系

保留用户既有研究规则：训练期IC、ICIR同为负可冻结反向；方向在验证期固定，方向化IC>0且ICIR>0按折报告，暂不发明跨折投票/平均通过规则。留出期不能因负号再翻向。

当前 `run_holdout` 输出预测IC/ICIR等诊断，而独立经济接受由既有六项及压力/风险/权重/账本门槛决定；本次**没有偷偷将留出IC/ICIR新增为硬门槛，也没有把它们删除**。因子训练内方向化折级报告与模型最终预测IC应区分。将预测IC/ICIR用于新独立接受规则，需在看结果前另行明确统计定义、有效IC天数和缺项行为；不能声称本次已经实现该额外门槛。

## 5. 无可靠历史时的前瞻预注册规则

以下是准备契约，不是已启动或已完成的前瞻服务。

1. 前置条件：取得实际正式accepted候选、冻结因子方向/特征/模型/成本/风险/标签和完整搜索谱系；新协议、匹配baseline及来源完整性验证就绪。
2. 起点：候选冻结和预注册均完成后的首个合格交易日。当前没有冻结候选，因此不伪造一个已经开始的日期。
3. 终点：启动前依据可信交易日历固定，同时覆盖至少252个计划交易日和12个日历月。策略每天的实际有效日期仍要满足252；节假日安排无法确认时不宣称日期已冻结。
4. 只做日常数据质量、身份连续性和风险监控；不以中间经济收益挑选候选/改参数。期末一次性查看确认结果；研究代理不接收留出择优反馈。
5. 期末缺数据/标签未成熟/独立性不能证明：`inconclusive`或`not_run`，不补零、不事后删差日期，不为了等盈利而延长终点。修复或改变候选需新观察计划。
6. 未确认前不接券商、不下单。旧快照身份不能直接覆盖未来数据；新的数据接入、时间证明、冻结包兼容和执行入口仍需真实条件具备后另行验收。此计划JSON不会自动启动现有holdout执行器。
